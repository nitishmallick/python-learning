# DNA Sequence Analyzer

A beginner bioinformatics project built using Python.

## Features
- Accepts a DNA sequence from the user
- Validates DNA bases (A, T, G, C)
- Calculates sequence length
- Counts A, T, G, and C nucleotides
- Calculates GC content as a percentage

## Technologies
- Python 3

## How to Run
1. Open Terminal in the project folder.
2. Run:

   `python3 dna_analyzer.py`

3. Enter a DNA sequence when prompted.

## Learning Goals
This project demonstrates Python input handling, strings, sets, conditional statements, counting, and basic DNA sequence analysis.
